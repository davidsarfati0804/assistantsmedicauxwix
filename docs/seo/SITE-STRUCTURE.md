## 3. Redirections 301

> À implémenter dans `next.config.ts` via `redirects()`.

| Source (ancienne URL Wix) | Destination | Code | Logique |
|--------------------------|-------------|------|---------|
| `/copie-de-accueil-1` | `/` | 301 | Doublon accueil |
| `/copie-de-accueil-2` | `/` | 301 | Doublon accueil |
| `/about-7` | `/assistants-medicaux` | 301 | "About" → page service principale |
| `/blank` | `/` | 301 | Page vide → accueil |
| `/copie-de-démarches` | `/avantages-demarches` | 301 | Doublon démarches |
| `/copie-de-demarches` | `/avantages-demarches` | 301 | Sans accent (robustesse) |
| `/book-online` | `/prendre-rendez-vous` | 301 | RDV en ligne |
| `/avantages-demarches` | `/avantages-demarches` | — | URL conservée (pas de redirection nécessaire) |

## 5. Checklist pré-lancement DNS

- [ ] Toutes les pages listées ci-dessus sont créées et indexables
- [ ] Redirections 301 implémentées dans `next.config.ts`
- [ ] `sitemap.xml` généré et listé dans `robots.txt`
- [ ] `robots.txt` configuré (allow tout sauf `/api/`)
- [ ] Metadata `title` + `description` sur chaque page
- [ ] Balises canoniques sur chaque page
- [ ] Google Analytics / Tag Manager configuré
- [ ] Google Search Console vérifié sur le nouveau domaine
- [ ] Aucun lien interne ne pointe vers les anciennes URLs Wix
- [ ] Test 404 sur toutes les anciennes URLs Wix → vérifier la redirection
